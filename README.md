# Portfólio Simplificado

Portfólio pessoal de Juliano Julio da Silva, desenvolvedor frontend, com links para redes sociais e uma galeria de projetos.

## Como visualizar

Não há build nem dependências. Basta abrir `index.html` diretamente no navegador.

## Estrutura

```
portifolio-simplificado/
├── index.html        # Página principal
└── src/
    ├── css/           # reset.css, estilos.css, responsivo.css
    ├── js/            # index.js (botão "Mostrar mais" projetos)
    └── imagens/        # Imagens de perfil e dos projetos
```

## Funcionalidade

O botão "Mostrar mais", na seção de projetos, exibe os projetos que ficam ocultos por padrão e depois se esconde.
